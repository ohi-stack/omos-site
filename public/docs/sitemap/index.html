Runtime & WordPress Boundary

omos.onegodian.com is the canonical runtime. omos.onegodian.org is the WordPress presentation/client surface. OneGodian Platform Plugin provides shared status integration across approved OneGodian WordPress properties; OMOS Core Tools v1.4.0 provides the specialized OMOS WordPress interface.

Publication Rule

Registered ODIN paths are not automatically public or Production. The XML sitemap contains implemented/addressable routes; registered-but-unbuilt pages remain in the canonical registry until dedicated routes are completed and verified.

Production boundary: repository implementation, deployment, and Production verification are separate states. OMOS-REF-0001 remains the runtime proof gate for durable Decision Record persistence and restart/reopen evidence.
