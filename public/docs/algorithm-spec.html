OneGodian Algorithm™

The canonical decision cycle is Observe → Distill → Align → Select → Execute → Verify. OMOS is the runtime that orchestrates this logic and records the resulting state.

OBSERVE → DISTILL → ALIGN → SELECT → EXECUTE → VERIFY
Alignment scores are decision-support signals, not a mathematical oracle for truth. Hard gates and evidence requirements are not averaged away by a high composite score.
