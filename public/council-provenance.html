Provenance precedes synthesis.

Every Council contribution should be attributable, hashable and status-qualified before it influences a governed synthesis. Human-relayed provider labels are assertions, not proof of origin.

Contribution envelope

Contribution ID, run ID, phase, assigned role, provider, model, connector ID, upstream request ID where available, input/output hashes, timestamps, latency, simulation state and provenance status.

Provenance states

verified_runtime_capture, simulated, human_relay_unverified, disputed, unresolved.

Council states

LIVE, HYBRID, SIMULATION and DEGRADED. A three-of-four run cannot be labeled four-of-four consensus.

Contradictions

Material factual conflicts should become first-class contradiction records with supporting/challenging contributions and evidence requirements.

QUALIFIED CONTRIBUTIONS → NORMALIZE → MEANING UNITS / CLAIMS → COMMON GROUND → MATERIAL REMAINDERS → CONTRADICTIONS → EVIDENCE → GOVERNED SYNTHESIS → HUMAN DISPOSITION → DECISION RECORD
Evidence hierarchy for state claims: external/runtime evidence > verified state > reasoned Council convergence > model confidence.
