Observe → Distill → Align → Select → Execute → Verify

Observe

Validate input, provenance and context.

Distill

Extract objective, claims, evidence, assumptions, conflicts and missing information.

Align

Evaluate dimensions, hard constraints, uncertainty and authorization.

Select

Choose permitted action, alternatives, rationale and required approvals.

Execute

Record actor, parameters, expected result and authorization.

Verify

Compare actual result with intended result and correct or escalate.

The seven-stage OMOS product rail operationalizes this cycle without treating deterministic execution as guaranteed truth.
