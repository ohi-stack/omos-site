OMOS Engineering Council Lifecycle

ISSUE → CLASSIFY → ASSIGN → FEATURE BRANCH → IMPLEMENT → PR → INDEPENDENT REVIEW → CI / SECURITY / REGRESSION → OMOS REVIEW → HUMAN APPROVAL → MERGE → DEPLOY → PRODUCTION VERIFICATION → ENGINEERING RECORD

Separation of duties

An agent that authored a change cannot be the sole final verifier of the same work.

Green CI is necessary

Tests demonstrate defined behavior but do not alone prove architecture, alignment or safe deployment.

Human approval

Consequential changes stop at a Human Gate before merge or production action.

Deployment proof

Merge is not completion. Exact deployed SHA, health, smoke tests and acceptance evidence complete the record.

Engineering Record

Retains issue, assigned agents, PR, reviewers, CI, approvals, merged SHA, deployed SHA, environment, verification result, rollback reference and final status.

ACC → OCP → OEG → Adapter / Runner is the execution authority spine. Agents do not self-authorize privileged actions.
