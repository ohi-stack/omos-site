OneGodian MCP inside the OMOS architecture.

MCP is an interoperability mechanism for exposing approved context, resources and tools. It is not the OMOS source of authority, the authoritative database, or a substitute for ACC/OCP authorization.

OMOS → O-H-I / QOHI → ACC → OCP / OEG → ONEGODIAN MCP STANDARD / GATEWAY → DOMAIN SYSTEMS

OMOS

Governing runtime, decision process, provenance and Decision Records.

ACC / OCP / OEG

Operational command, authorization policy and governed execution.

MCP Gateway

Provider-neutral tool/resource interface for approved clients and domain systems.

Domain systems

QRV, ODIN, OBP-1, Time, real estate, cloud and other source systems retain their own authority and data boundaries.

MCP provides interoperability. OMOS provides governance and records. ACC provides orchestration and approved execution. Domain systems remain sources of record.
