OMOS API

Public runtime metadata is exposed through health, manifest, providers, and persistence status endpoints. Governed processing and Council operations require authenticated server-side access.

  • GET /api/health
  • GET /api/manifest
  • GET /api/v1/providers
  • GET /api/v1/persistence

Never expose OMOS API keys or provider credentials in browser code.
