## Required public-site boundaries

1. **Model agreement is not factual verification.**
2. **Provider configuration is not a successful live connection test.**
3. **A repository commit is not deployment proof.**
4. **Deployment is not Production certification without source parity and behavioral evidence.**
5. **Human authorization remains required for consequential external actions.**
6. **UTC is canonical system time; Gregorian is controlling for civil/legal records; OneGodian Time is supplemental where used.**
7. **ONEGODIAN, LLC is the commercial/software/IP entity; INO governance/religious-society language must remain contextually separate.**
8. **Scientific claims must be classified according to actual empirical support.**
9. **Secrets never belong in client-side code, public API payloads, logs, Decision Records, or source control.**
10. **If a capability is not fully operational, documented, repeatable, and testable, it does not exist in the current operational version.**

## Material intentionally not promoted to mainstream live-site claims

The following may remain in research, artifacts, education, historical records, or future modules unless separately implemented and verified:

- speculative AGI/ASI claims;
- synthetic-personhood or autonomous-sovereignty claims;
- metaphysical/cosmological claims stated as scientific fact;
- token/NFT/financial-instrument functionality not separately activated and reviewed;
- legal-recognition or institutional-acceptance guarantees;
- autonomous consequential execution;
- external-system write access without explicit connector permissions and human/policy authorization.
