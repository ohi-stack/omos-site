2. **Provider configuration is not a successful live connection test.**
3. **A repository commit is not deployment proof.**
4. **Deployment is not Production certification without source parity and behavioral evidence.**
5. **Human authorization remains required for consequential external actions.**
6. **UTC is canonical system time; Gregorian is controlling for civil/legal records; OneGodian Time is supplemental where used.**

9. **Secrets never belong in client-side code, public API payloads, logs, Decision Records, or source control.**

## Connector distinction

**Model Gateway** = who OMOS reasons with.  
**Data / Action / Environment Gateway** = what OMOS may securely read, synchronize, invoke, or operate.

Data synchronization should preserve source, permission scope, direction, object identity, timestamps, external IDs, OMOS IDs, provenance, conflict policy, health, and audit events. Synchronization does not establish truth or authority.

## Deployment boundary

This integration record documents what belongs in the canonical site repository. It does not prove that `omos.onegodian.com` is running a given commit. Production status remains governed by exact deployed-SHA, persistence, runtime, reference-run, and restart/reopen evidence.
