# OMOS.OneGodian.com Mega Menu v2.0

**Status:** Information Architecture Specification

## Main Navigation

The public navigation should prioritize customer tasks while preserving institutional and developer access.

| Main Menu | Column 1 | Column 2 | Column 3 | Column 4 | Column 5 | Column 6 |
|---|---|---|---|---|---|---|
| **OMOS** | What Is OMOS | How It Works | OneGodian Protocol | OneGodian Algorithm | OHI | Architecture |
| **WORKSPACE** | Ask OMOS | Decision Review | Document Review | Projects | Decision Records | History |
| **COUNCIL** | AI Council | Council Workspace | OpenAI | Claude | Gemini | Grok |
| **OLLM** | OneGodian LLM | OLLM Runtime | Model Gateway | Knowledge | Evaluations | Developer Access |
| **TOOLS** | Layer 1 | Alignment Engine | Belief Mapper | Output Pipeline | Verification | All Tools |
| **DEVELOPERS** | Developer Hub | API | Model Connectors | Data Connectors | Runtime Status | Documentation |
| **PRICING** | Free | OMOS Pro | OMOS Council | OMOS Business | Implementation | Shop |

## Persistent Header Actions

- **OMOS logo** → `/`
- **Runtime status** → `/status` or `/health`
- **Sign In** → account/login
- **ASK OMOS** → `/ask`

`ASK OMOS` should remain the dominant primary CTA.

## UX Rules

- Desktop: mega-menu grid with clear section headings.
- Mobile: accordion navigation with no duplicated nested links.
- Preserve shared global shell rather than hardcoding page-specific nav copies.
- Always display maturity/runtime status accurately.
- Do not surface routes as active products until their implementation status supports that claim.
