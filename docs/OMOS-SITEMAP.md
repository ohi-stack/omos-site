## Authority boundary

`omos.onegodian.com` owns governed runtime state, provider state, Council execution, persistence, Decision Records, and runtime APIs.

`omos.onegodian.org` is a presentation/client surface. It does not become a second OMOS runtime or Decision Store.

MCP provides interoperability. OMOS governs runtime use. ACC may orchestrate authorized execution. Connected domain systems remain their own sources of record.

## Publication rule

A registered ODIN page is not automatically a live public page. The public XML sitemap should contain implemented/addressable routes only. Registry-defined pages that do not yet have a dedicated public route remain documented in the ODIN registry until implementation and verification are complete.
