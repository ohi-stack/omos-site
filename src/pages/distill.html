Layer 1 • Distill • Structured Intake

Turn a messy prompt into a clean working problem without deleting material meaning.

OMOS Distill is the customer-facing name for Layer 1. It identifies the objective, facts and claims supplied, requirements, constraints, questions, evidence references, ambiguities, contradictions, risks, and potentially hostile or authority-conflicting instructions before the request moves deeper into the runtime.

What Distill should preserve

Names, dates, prohibitions, deadlines, budgets, evidence, unresolved conflicts, user intent, and other material constraints should survive normalization. Noise reduction must not become meaning deletion.

Meaning Units

Complex input can be decomposed into smaller Meaning Units so later stages can compare claims and constraints explicitly instead of treating a long prompt as one opaque block.

Quarantine, not concealment

Instructions that attempt to bypass authority, erase logs, fabricate proof, or override the governing system can be quarantined for review. Quarantine status should remain visible in the run record.

Next stage

Distilled input moves to the Alignment Engine, then to Council or other configured processing according to the run.
