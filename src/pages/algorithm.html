The OneGodian Algorithm™

Observe → Distill → Align → Select → Execute → Verify

The OneGodian Algorithm is the decision and evaluation cycle beneath OMOS. It provides a repeatable way to move from raw input to a selected course of action while keeping evidence, constraints, authorization, execution, and verification distinct.

1. Observe

Receive the situation, facts supplied, environment, relevant source material, goals, and constraints without prematurely deciding what the answer should be.

2. Distill

Decompose input into Meaning Units, preserve material facts and prohibitions, identify ambiguity and noise, and create a clean working representation.

3. Align

Evaluate candidates across explicit dimensions and hard gates rather than hiding tradeoffs inside one opaque score.

4. Select

Choose the strongest supported path based on the evidence available, alternatives, constraints, risk, and unresolved disagreement. Selection is not the same thing as external execution.

5. Execute

Carry out only actions that are within the authorized scope. Consequential external actions may require a separate Human Gate, ACC/execution-control path, professional review, or domain-system authorization.

6. Verify

Compare the result against the objective, acceptance criteria, evidence, and actual outcome. Verification can trigger revision rather than forcing a prior decision to appear correct.

Runtime mapping

The current customer-facing OMOS path is Ask → Distill → Alignment → Council → Governed Synthesis → Decision Record → History, with the Human Gate governing the record transition where required.
