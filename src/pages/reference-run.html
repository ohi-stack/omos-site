OMOS-REF-0001 • Reference Run • Production Evidence

The first governed end-to-end production proof.

OMOS-REF-0001 is the milestone used to prove that the current OMOS software can execute and preserve one governed decision transaction on the canonical host. It exists to separate implemented architecture from demonstrated production behavior.

Required flow

Browser input → Layer 1 → Alignment → Council → Governed Synthesis → Human Gate → Decision Record → PostgreSQL → Dashboard History → restart/redeploy → reopen the same Decision ID.

PASS requirements

  • The deployed runtime identifies its exact source revision and expected OMOS version.
  • Production persistence reports PostgreSQL, durable, and initialized.
  • A real governed run produces a unique Decision ID.
  • The server records the Human Gate disposition.
  • The complete record can be reopened from authorized History.
  • After runtime restart or redeploy, the same Decision ID still exists.
  • Ownership isolation and revision/hash lineage remain intact.

Automatic fail conditions

Memory-only persistence, a lost record after restart, unresolved deployed source revision, mismatched deployment SHA, placeholder production credentials, or fabricated provider status cannot be counted as a PASS.

Current status

Production certification remains in progress until all live-host evidence gates are satisfied. Repository tests and a live URL are necessary but not sufficient.
