Artifacts • Source Records • Implementation Evidence

The source library behind OMOS.

OMOS artifacts include authored source documents, architecture diagrams, whitepapers, specifications, system prompts, manifests, schemas, animations, simulations, test evidence, release records, and implementation-support materials. The artifact library exists to make source lineage visible instead of asking users to rely only on summaries.

Core artifact groups

  • OneGodian Algorithm whitepaper and implementation specifications
  • OneGodian Protocol drafts and interoperability documents
  • OHI runtime, Council, GCD Synthesis, and output-pipeline materials
  • OneGodian AI/system-prompt materials
  • OTS-V5 corrected timekeeping standard and validation materials
  • OneGodian Frequency Standard research materials
  • OMOS manifests, API contracts, schemas, Decision Record definitions, and runtime evidence
  • OMOS Compliance Test Suite and profile specifications
  • Connection, adapter, MCP, Engineering Council, and developer-agent records
  • Belief Mapper and Digital Sanctuary source materials
  • ODIN-SCI-0004 OneGodian Particle Science theoretical/research-development record
  • Release, migration, CI, restart, and production-evidence records

Source classes

Artifacts should identify whether they are authored source, working draft, technical specification, implementation artifact, runtime evidence, research/theoretical material, or historical/superseded. These classes should not be conflated.

Evidence rule

A document describing a capability is not proof the capability is deployed. Runtime evidence, tests, deployed SHA, persistence state, and reference-run records are separate artifacts.
