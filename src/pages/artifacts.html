Artifact handling rule

OMOS distinguishes source artifact, implementation evidence, runtime evidence, and external validation. A PDF, specification, model output, repository commit, or Council consensus can establish provenance or implementation status, but none should automatically be treated as independent external validation of the underlying claim.
