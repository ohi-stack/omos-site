Status • Maturity • Deployment Evidence

Know what is built, staged, deployed, and verified.

OMOS uses component-level maturity instead of a blanket platform label. A live website does not make every planned capability Production.

Maturity model

Conceptual → Prototype → Functional → Verified → Production

Functional means the component is available for controlled validation with known limitations. Verified requires evidence against defined acceptance criteria. Production requires the capability to be operational, documented, repeatable, monitored where appropriate, and proven in the target environment.

Four states visitors should distinguish

  • Implemented on main — code or content exists on the canonical repository branch.
  • Staged in PR — proposed change is under review and should not be described as deployed.
  • Deployed — a revision is serving the canonical host.
  • Production-verified — the deployed revision has passed the required behavioral evidence gates.

Claims discipline
