Commerce integrity rule

The paid runtime contract is Stripe Checkout → verified server-side payment webhook → OMOS entitlement → run allowance → governed run → Decision Record → Dashboard History. A browser success redirect alone must never unlock paid access.

Current boundary: do not advertise unlimited Council use, team functionality, API access, durable history, exports, or a specific live provider unless the corresponding production capability is enabled and tested.
