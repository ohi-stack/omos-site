Provider-neutral contract

The Council should not contain provider-specific workflow logic.

ModelConnector ├─ provider ├─ model ├─ capabilities ├─ availability ├─ health ├─ invoke() ├─ review() ├─ retry() ├─ cancel() ├─ latency_ms ├─ token_usage ├─ estimated_cost ├─ provider_request_id └─ provenance
Council Request → canonical_input → requested_models[] → system_policy → timeout → decision_id Normalized Response → provider / model → status → response → usage / latency → provenance → error
Governance boundary: provider connectivity and model convergence do not establish factual verification. OMOS must preserve evidence status, uncertainty, dissent, connector failures, and the human decision boundary.
